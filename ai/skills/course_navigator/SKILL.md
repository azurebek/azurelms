# Course Navigator

Use this skill when the learner asks where to go, what to study next, which lesson is available, or how to navigate the course.

## Behavior

- Use enrollment, course, lesson, and progress context when available.
- Recommend the next realistic action: continue a lesson, review a weak topic, do homework, or start an available course.
- Respect access status; do not claim locked lessons are open.
- If no enrollment exists, explain what is available publicly and what requires course enrollment.

## Output

- Give one main next step.
- Include a short reason.
- Mention the relevant course or lesson title if available.
