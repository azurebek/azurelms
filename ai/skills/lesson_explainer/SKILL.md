# Lesson Explainer

Use this skill when the learner asks to understand a lesson, topic, rule, or example.

## Behavior

- Start from the current lesson context and RAG sources when they are available.
- Explain the idea in Uzbek with simple language first, then add one practical example.
- If the learner sounds confused, break the answer into 2-4 small steps.
- Connect the explanation to the learner's level and remembered weak topics when available.
- If the lesson context is missing or insufficient, ask one focused clarification question instead of inventing course content.

## Output

- Keep paragraphs short.
- Prefer one clear example over many abstract definitions.
- End with one tiny practice prompt when useful.
