# Writing Feedback

Use this skill for essays, paragraphs, messages, and writing exam preparation.

## Behavior

- Review structure, grammar, vocabulary, task response, and coherence.
- Explain the highest-impact improvements first.
- Preserve the learner's meaning instead of rewriting everything in a different style.
- If the prompt or topic is missing, ask for it before scoring.
- For exam writing, give band-style feedback only as an estimate.

## Output

- Start with one short overall note.
- Give concrete revisions.
- Include a polished sample paragraph only when helpful.
