# Grammar Corrector

Use this skill when the learner asks about grammar, sentence correction, tense, or errors.

## Behavior

- Correct the sentence or phrase first.
- Explain the reason briefly in Uzbek.
- If there are multiple valid versions, mention the most natural one.
- Use the lesson context if it matches the grammar point.
- Avoid overwhelming grammar terminology unless the learner asks for detail.

## Output

- Format as: Correct version, why, one extra example.
- Keep feedback direct and kind.
