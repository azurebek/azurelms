04 · Rules

No-improvisation checklist

  1. Start with an existing token or component from this page.
  2. Use the 4px spacing scale unless a measured Coursera reference requires an off-grid value.
  3. Use Source Sans 3 and the documented weights. Do not add a new font inside a page.
  4. Keep public pages inside the 1408px desktop shell with 32px inline padding.
  5. When a new pattern is truly needed, add it to style.css, this page, and DESIGN-SYSTEM.md together.
  6. Verify at 1536px desktop plus one tablet and one mobile viewport before promoting a prototype.
